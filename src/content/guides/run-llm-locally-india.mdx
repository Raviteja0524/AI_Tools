Running AI models locally means having a powerful AI assistant on your own computer — no internet required, no monthly subscription, and no data ever leaving your machine. In 2026, this is not just possible but straightforward.

This guide walks you through the complete setup, from understanding what's needed to chatting with a local AI in under 10 minutes.

## Why Run AI Locally? (Especially in India)

Before the how, let's understand the why:

**Cost**: Cloud AI services charge in dollars. At current exchange rates, Claude Pro costs ₹1,699/month, ChatGPT Plus costs ~₹1,600/month. Local models are free forever — you just need your own hardware.

**Privacy**: Every message you send to ChatGPT, Claude, or Gemini is processed on their servers. For freelancers handling client code, students working on research, or anyone with sensitive data — local models keep everything on your device.

**Offline access**: India's internet connectivity can be unreliable — especially in tier 2/3 cities, during travel, or inside certain corporate networks. Local models work everywhere, always.

**No rate limits**: Free cloud tiers throttle usage aggressively. Local models have no limits — run them all day, every day.

<Callout type="india">
  Local LLMs are especially valuable for Indian users: they eliminate dollar-denominated subscription costs, work on patchy rural internet connections, and comply with corporate IT policies that block external AI services.
</Callout>

## What You Need

### Hardware Requirements

| Your Machine | Can You Run LLMs? | Which Models |
|---|---|---|
| MacBook Air M1/M2/M3 (8GB) | ✅ Yes | Llama 3.2 3B, Phi-4 mini, Gemma 2B |
| MacBook Air M1/M2/M3 (16GB) | ✅ Yes | Llama 3.2 8B, Mistral 7B, Gemma 9B |
| Windows laptop, 8GB RAM, any CPU | ✅ Yes (slower) | Llama 3.2 3B, Phi-4 mini |
| Windows laptop, 16GB RAM, no GPU | ✅ Yes | Llama 3.2 7B (CPU inference) |
| Linux desktop, NVIDIA GPU (4GB VRAM) | ✅ Yes (fast) | 7B–13B models on GPU |
| Old laptop with 4GB RAM | ⚠️ Limited | Only tiny 1B models — not very useful |

**Verdict for most Indian users**: An 8GB RAM machine can run small-to-medium models that are genuinely useful. 16GB is the sweet spot where you get capable models (7B parameters) running at a comfortable speed.

### Storage Requirements
- Ollama itself: ~500MB
- Each model: 2–8GB (downloaded once, cached permanently)
- Recommended free space: 20GB+ (to store 2–3 models)

### Software Requirements
- Windows 10/11, macOS 12+, or any modern Linux distro
- No Python installation needed
- No CUDA configuration needed (Ollama handles it)

## Step 1: Install Ollama

<ToolMention slug="ollama" />

**macOS** (open Terminal and paste):
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

**Linux** (same command works on Ubuntu, Debian, Fedora):
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

**Windows**: Go to [ollama.com](https://ollama.com), download the installer (`.exe`), and run it like any other Windows app. Then open Command Prompt or PowerShell.

After installation, verify it works:
```bash
ollama --version
```
You should see a version number. Done.

## Step 2: Download and Run Your First Model

For beginners, start with **Llama 3.2 3B** — it's small (~2GB), fast even on modest hardware, and genuinely useful:

```bash
ollama run llama3.2:3b
```

Ollama will download the model (this takes a few minutes on first run), then open an interactive chat:

```
>>> Send a message (/? for help)
```

Try asking it something:
```
>>> Explain recursion in simple terms
>>> Write a Python function to find prime numbers
>>> Summarize this text: [paste any article]
```

<Callout type="tip">
  **Slow download?** Ollama downloads models from the internet once and caches them locally. If your home internet is slow, schedule the download overnight. University and office networks are often faster — do the initial download there.
</Callout>

## Step 3: Try Better Models (Based on Your RAM)

Once you're comfortable, upgrade to more capable models:

**8GB RAM — Best choices**:
```bash
ollama run llama3.2          # 3B default — fast, capable
ollama run phi4-mini         # Microsoft's efficient small model
ollama run gemma3:4b         # Google's model, great for multilingual
```

**16GB RAM — Better choices**:
```bash
ollama run llama3.2:8b       # Much more capable, still fast
ollama run mistral           # 7B — fast and strong
ollama run qwen2.5:7b        # Excellent for code, decent Hindi
```

**32GB RAM or NVIDIA GPU**:
```bash
ollama run llama3.3:70b      # Near-cloud quality
ollama run deepseek-r1:32b   # Excellent reasoning
```

## Step 4: Add a Web Interface (Optional but Recommended)

The command-line chat is fine, but most people prefer a browser-based interface. **Open WebUI** gives you a ChatGPT-like experience connected to your local Ollama models.

**If you have Docker installed**:
```bash
docker run -d -p 3000:8080 \
  --add-host=host.docker.internal:host-gateway \
  -v open-webui:/app/backend/data \
  ghcr.io/open-webui/open-webui:main
```
Then open `http://localhost:3000` in your browser.

**Don't have Docker?** Try **LM Studio** instead — it's a desktop app with a built-in chat interface:

<ToolMention slug="lm-studio" />

LM Studio is a great alternative for Windows users especially — it has a polished desktop GUI, model browser, and local server with no Docker needed.

## Step 5: Use Local AI in Your Code Editor

This is where local LLMs become genuinely powerful for developers — a free GitHub Copilot alternative that runs entirely on your machine.

### With VS Code (using Continue.dev)

1. Install the [Continue](https://continue.dev) extension in VS Code
2. Open Continue settings (`.continue/config.json`):
```json
{
  "models": [
    {
      "title": "Llama 3.2 (Local)",
      "provider": "ollama",
      "model": "llama3.2"
    }
  ],
  "tabAutocompleteModel": {
    "title": "Qwen 2.5 Code (Local)",
    "provider": "ollama",
    "model": "qwen2.5-coder:7b"
  }
}
```
3. Press `Ctrl+L` (or `Cmd+L` on Mac) to open the AI chat panel
4. Use `Tab` for inline code completions

You now have a free, offline, private AI coding assistant.

### With Cursor (if you have a subscription)

Cursor can use Ollama as a custom model provider. Go to Settings → Models → Add Model, and point it to `http://localhost:11434/v1` with model name `llama3.2` (or whichever model you're running).

<Callout type="warning">
  Ollama must be running in the background for code editor integrations to work. On macOS/Linux it starts automatically as a service after installation. On Windows you may need to run `ollama serve` in a terminal first.
</Callout>

## Common Issues and Fixes

**"ollama: command not found" on macOS**:
```bash
export PATH=$PATH:/usr/local/bin
# or
export PATH=$PATH:/opt/homebrew/bin
```
Add this to your `~/.zshrc` or `~/.bashrc`.

**Model is very slow** (takes 10+ seconds per response):
- You're running a model too large for your RAM
- Switch to a smaller model: `ollama run llama3.2:3b` instead of 8B
- Close other heavy apps (Chrome tabs, IDEs) to free RAM

**Download fails or is very slow**:
- Ollama downloads from Cloudflare CDN — speeds are generally good in India
- Try at off-peak hours (late night / early morning)
- If behind a corporate proxy, set `HTTPS_PROXY` environment variable

**Model responses in wrong language**:
- Explicitly ask in your prompt: "Reply in English" or "Respond in Hindi"
- Or add a system prompt: `ollama run llama3.2 --system "You are a helpful assistant. Always reply in English."`

## What Local AI Can't Do (Yet)

Be realistic about limitations:
- Local 7B–8B models are roughly on par with GPT-3.5 or Claude 2 — capable, not cutting-edge
- Context windows are typically 8K–32K tokens (vs 200K for cloud Claude)
- No internet access — can't browse web or fetch current information
- Image generation requires separate tools (Stable Diffusion, not covered here)
- Voice interaction needs additional setup

For most everyday tasks — coding help, writing assistance, document summarization, Q&A — local models are more than sufficient.
