## What Is Ollama?

Ollama is a free, open-source tool that lets you download and run large language models (LLMs) locally on your computer. It handles all the complexity of model management — downloading, quantizing, and serving models — through a simple command-line interface and a local API that mirrors OpenAI's API format.

Supported platforms: macOS (Apple Silicon + Intel), Linux, Windows (WSR 2 or native).

## Key Features

### 1. One-Command Model Downloads
Running a model is as simple as:
```bash
ollama run llama3.2
```
Ollama downloads the model, configures it, and opens an interactive chat. No Python, no pip, no CUDA headaches.

### 2. Massive Model Library
Ollama's library hosts 100+ models including:
- **Llama 3.2 / 3.3** (Meta) — Best general-purpose open-source models
- **Mistral / Mixtral** — Fast, capable European models
- **Gemma 3** (Google) — Efficient models with strong multilingual support
- **Qwen 2.5** (Alibaba) — Excellent for code and Chinese/Asian languages
- **Phi-4** (Microsoft) — Small but surprisingly capable
- **DeepSeek R1** — Strong reasoning in a local package
- **Code Llama / Starcoder** — Specialized for code generation

### 3. OpenAI-Compatible API
Ollama runs a local server at `http://localhost:11434` with an API that mirrors OpenAI's format. This means you can point any app that works with OpenAI — Cursor, Continue.dev, Open WebUI, LangChain — to your local Ollama instance instead:
```
Base URL: http://localhost:11434/v1
API Key: ollama (or any string)
```

### 4. Multiple Models Simultaneously
You can run different models for different tasks and switch between them without restarting anything. Ollama manages memory allocation automatically.

### 5. Model Customization with Modelfiles
Create custom models with specific system prompts, temperature settings, or fine-tuned base models using a `Modelfile`:
```
FROM llama3.2
SYSTEM "You are a helpful assistant specializing in Indian tax law."
PARAMETER temperature 0.3
```

<Callout type="tip">
  **For students with limited storage**: Use quantized versions of models. `llama3.2:3b` uses ~2GB of disk and RAM and runs on almost any laptop. It's less capable than the 70B version but still remarkably useful for coding help, summarization, and Q&A.
</Callout>

## Setting Up Ollama (5-Minute Guide)

**macOS / Linux**:
```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama run llama3.2
```

**Windows**: Download the installer from ollama.com, run it, then open Command Prompt and type `ollama run llama3.2`.

After the model downloads (one-time, ~4–5GB for a 7B model), you have a fully functional AI assistant that runs without internet.

## Connecting Ollama to Your Code Editor

The real power comes from using Ollama as the backend for AI coding tools:

**With Continue.dev** (VS Code / JetBrains):
```json
{
  "models": [{
    "title": "Llama 3.2 (Local)",
    "provider": "ollama",
    "model": "llama3.2"
  }]
}
```

**With Open WebUI** (browser-based ChatGPT-like interface):
```bash
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway \
  -v open-webui:/app/backend/data \
  ghcr.io/open-webui/open-webui:main
```
Then open `http://localhost:3000` and select your Ollama models.
